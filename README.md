# Banking Database Management System using MySQL

## Project Overview

The **Banking Database Management System** is a MySQL-based database
project designed to manage bank branches, customers, account types, bank
accounts, and financial transactions. It demonstrates relational
database design and practical SQL concepts for maintaining accurate and
consistent banking records.

## Project Objectives

-   Design and implement a relational banking database using MySQL.
-   Store and manage branch, customer, account, and transaction
    information.
-   Maintain relationships between tables using primary and foreign
    keys.
-   Apply database normalization (1NF, 2NF, and 3NF).
-   Perform data retrieval and manipulation using SQL.
-   Generate useful banking reports and summaries.
-   Maintain data consistency using constraints and transactions.

## Technologies Used

-   **Database:** MySQL
-   **Query Language:** SQL
-   **Database Tool:** MySQL Workbench

## Database Design

The database contains five main tables:

  -----------------------------------------------------------------------
  Table                               Purpose
  ----------------------------------- -----------------------------------
  `Branches`                          Stores branch details, including
                                      branch name and location.

  `Customers`                         Stores customer names, phone
                                      numbers, email addresses, and
                                      addresses.

  `Account_Types`                     Stores account categories such as
                                      Savings and Current.

  `Accounts`                          Stores account details, including
                                      branch, customer, account type,
                                      account number, balance, opening
                                      date, and status.

  `Transactions`                      Stores transaction details,
                                      including account, transaction
                                      type, amount, date, and
                                      description.
